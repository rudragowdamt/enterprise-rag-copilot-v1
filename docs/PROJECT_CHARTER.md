# Project Charter

## Product
Enterprise Knowledge & Incident Resolution RAG Copilot

## Persona
L1/L2/L3 support engineer, incident manager, application owner, operations lead.

## Core promise
Ask an operational question and receive a grounded response based only on approved enterprise knowledge, with source evidence and an explicit "insufficient evidence" behavior.

## Why RAG
Enterprise facts change and often must remain traceable to internal sources. RAG retrieves relevant enterprise context at query time rather than expecting an LLM to memorize private operational knowledge.

## Portfolio outcomes
Demonstrate ingestion, chunking, embeddings, vector retrieval, metadata, prompt grounding, citations, evaluation, reranking, API/UI, AWS deployment, security, observability and cost awareness.
