# Axway API Gateway HTTP 504 Runbook
Document ID: RB-AXWAY-001
Platform: Axway API Gateway

## Meaning
HTTP 504 generally indicates that the gateway did not receive a timely response from an upstream or downstream dependency.

## Troubleshooting
1. Capture API name, gateway node, correlation ID, backend endpoint and timestamp.
2. Confirm whether the 504 is generated by Axway or another intermediary.
3. Test backend connectivity from the gateway network.
4. Check DNS resolution, routing, firewall and TLS handshake.
5. Compare backend response time with configured gateway timeout.
6. Review recent policy, routing or backend URL changes.
7. Check backend health, thread/connection pools and database dependencies.
8. Search historical incidents for the same API and dependency.
9. Do not simply increase timeout until the slow dependency is understood.

## Escalation
Escalate to the backend owner when the gateway is healthy but the backend is slow or unavailable. Engage network/security teams for connectivity or TLS failures.
