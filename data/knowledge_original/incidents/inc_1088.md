# Incident
Order creation intermittently returned HTTP 503 during peak traffic.
# Root cause
A connection leak exhausted the application database pool.
# Resolution
The faulty code path was patched, instances were rolled, and pool utilization returned to normal. Increasing the pool size alone was rejected because it would only delay recurrence.
